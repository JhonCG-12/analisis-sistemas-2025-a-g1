# 📘 Sistema de Gestión de Notas en Corhuila

## 📌 Resumen Ejecutivo

Este documento aborda el diseño e implementación de un sistema de gestión de notas para la Corporación Universitaria del Huila (Corhuila), con el objetivo de optimizar la administración académica. Se presentan los requerimientos funcionales fundamentales y se analizan diferentes métodos para la recolección de información, permitiendo una solución eficiente y escalable.

## 🔎 Requerimientos Funcionales (RF)

Para garantizar la funcionalidad del sistema, se establecen los siguientes requisitos clave:

- **RF1: Registro de Datos de Personas** → Se almacena la información esencial de los usuarios (estudiantes y profesores), asegurando la unicidad de los registros.
- **RF2: Registro de Estudiantes** → Permite la inscripción de alumnos dentro del sistema con su respectiva información académica.
- **RF3: Registro de Profesores** → Facilita la incorporación de docentes y la asignación de materias de acuerdo con su carga académica.

## 📊 Métodos de Recolección de Información

Para el desarrollo de este sistema, se consideran tres enfoques principales para la recopilación de datos:

1. **Enfoque Técnico (Sistema Automatizado):** Se basa en el diseño y desarrollo de software especializado para la gestión de notas.
2. **Enfoque Metodológico (Investigación Procesual):** Consiste en la recopilación de información a través de entrevistas y análisis de los procesos administrativos existentes.
3. **Enfoque Cuantitativo (Encuestas y Opinión Pública):** Implica la recolección de percepciones de estudiantes y docentes respecto al sistema de evaluación y calificación.

## 📈 Comparación y Aplicabilidad

Cada enfoque posee características y beneficios específicos:

- **El enfoque técnico** permite la automatización de procesos y garantiza mayor precisión en la gestión académica.
- **El enfoque metodológico** ayuda a comprender los flujos de trabajo, facilitando la identificación de áreas de mejora.
- **El enfoque cuantitativo** permite medir la satisfacción y detectar posibles ajustes basados en la retroalimentación de los usuarios.

## ✅ Conclusiones y Recomendaciones

- Se recomienda priorizar el **enfoque técnico**, ya que permite una automatización eficaz, optimizando la gestión de notas.
- Es fundamental realizar **pruebas de validación** antes de la implementación del sistema para garantizar su correcto funcionamiento.
- Se sugiere la integración de **tecnologías emergentes** como inteligencia artificial y análisis de datos para mejorar la experiencia del usuario y la eficiencia del sistema.

Este documento busca proporcionar una base sólida para la implementación de un sistema de gestión de notas confiable y alineado con las necesidades académicas de Corhuila. 🚀
